\doxysubsection{Detailed Description}
The child class \doxylink{classofeli_1_1_geodesic_a_c}{Geodesic\+AC} implements a function to calculate specifically speed {\itshape Fd} based on a geodesic model, an edge-\/based energy functional. An Otsu\textquotesingle{}s method is performed in order to find the high values of the gradient to converge even when the initialization of the curve is far of the solution.
