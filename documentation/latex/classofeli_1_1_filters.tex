\doxysubsection{Detailed Description}
This class implements filters and noise functions for RGB images. ~\newline
There are two linear filters :\+ a mean filter and a gaussian filter. ~\newline
Moreover, there are seven operators of mathematical morphology (erosion, dilation, morphological gradient, opening, closing and the both top-\/hat transforms) with a square for a structuring element. ~\newline
Furthermore, there are two edge preserving filters :\+ a median filter and a Perona-\/\+Malik anisotropic diffusion. ~\newline
The order filters (i.\+e. the median filter and the morphological filters) are implemented in a naïve version and in an optimized version (using Simon Perreault\textquotesingle{}s algorithm). ~\newline
In addition, there are three functions to add noise, implemented with the C++ standard library random distributions:\+ gaussian white noise, impulsional noise or salt and pepper and speckle.
