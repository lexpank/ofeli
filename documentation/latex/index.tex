Ofeli (Open, Fast and Efficient Level set Implementation) is a Qt desktop application for image filtering and active-\/contour segmentation.



\hypertarget{index_autotoc_md1}{}\doxysection{\texorpdfstring{Requirements}{Requirements}}\label{index_autotoc_md1}

\begin{DoxyItemize}
\item CMake 3.\+16 or newer
\item Qt 6.\+11.\+1 with Widgets, Print\+Support, and Linguist\+Tools
\item A C++17 compiler
\end{DoxyItemize}

The project is configured for Linux, mac\+OS, and Windows. Linux builds and the core smoke test run in CI.\hypertarget{index_autotoc_md2}{}\doxysection{\texorpdfstring{Build and test}{Build and test}}\label{index_autotoc_md2}

If Qt is installed outside CMake\textquotesingle{}s default search path, add {\ttfamily -\/DCMAKE\+\_\+\+PREFIX\+\_\+\+PATH=/\+path/\+to/\+\+Qt/\+6.11.\+1} to the configure command.

The French translation is compiled from Ofeli\+\_\+fr.\+ts during the build; no generated .qm file is required in the source tree.\hypertarget{index_autotoc_md3}{}\doxysection{\texorpdfstring{Qt Creator}{Qt Creator}}\label{index_autotoc_md3}
Open the repository\textquotesingle{}s {\ttfamily CMake\+Lists.\+txt} in Qt Creator and select a Qt 6.\+11.\+1 CMake kit. Configure a fresh build directory, then build the {\ttfamily Ofeli} target. On an Apple Silicon Homebrew installation, set CMake\textquotesingle{}s {\ttfamily CMAKE\+\_\+\+PREFIX\+\_\+\+PATH} to {\ttfamily /\+opt/\+homebrew/\+opt/\+qt} if Qt Creator does not find Qt automatically.

If Qt Creator reports {\ttfamily No rule to make target \textquotesingle{}all\textquotesingle{}}, it is using an old qmake/\+\+Makefile build configuration. Remove that build configuration in Qt Creator and re-\/open {\ttfamily CMake\+Lists.\+txt}; do not open the old {\ttfamily .pro} project.\hypertarget{index_autotoc_md4}{}\doxysection{\texorpdfstring{Release smoke checklist}{Release smoke checklist}}\label{index_autotoc_md4}
