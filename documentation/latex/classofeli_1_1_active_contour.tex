\doxysubsection{Detailed Description}
The class \doxylink{classofeli_1_1_active_contour}{Active\+Contour} contains the implementation of the Fast-\/\+Two-\/\+Cycle (FTC) algorithm of Shi and Karl as it describes in their article "{}\+A real-\/time algorithm for the approximation of level-\/set based curve evolution"{} published in IEEE Transactions on Image Processing in may 2008. This class should be never instantiated because the function to calculate the external speed {\itshape Fd} is too general. The 3 classes \doxylink{classofeli_1_1_a_cwithout_edges}{ofeli::\+\+ACwithout\+Edges}, \doxylink{classofeli_1_1_a_cwithout_edges_y_u_v}{ofeli::\+\+ACwithout\+Edges\+YUV} and \doxylink{classofeli_1_1_geodesic_a_c}{ofeli::\+\+Geodesic\+AC}, inherit of the class \doxylink{classofeli_1_1_active_contour}{Active\+Contour}, with for each class it own implementation of this function.
