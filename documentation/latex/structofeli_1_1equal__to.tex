This class defines function objects for the equality comparison operation. Generically, function objects are instances of a class with member function {\ttfamily operator()} defined. This member function allows the object to be used with the same syntax as a regular function call, and therefore it can be used in templates instead of a pointer to a function. {\ttfamily \doxylink{structofeli_1_1equal__to}{equal\+\_\+to}} has its {\ttfamily operator()} member defined such that it returns {\ttfamily true} if its two arguments compare equal to each other using {\ttfamily operator==}, and {\ttfamily false} otherwise. This class can be used with the template functions {\ttfamily \doxylink{classofeli_1_1list_aaeedac18b70d233644d84c7ad3a9a3fa}{list$<$\+T$>$::\+sort(\+Binary\+Predicate compare)}} and list$<$\+T$>$::\+put\+\_\+away(\+Binary\+Predicate compare).
