\doxysubsection{Detailed Description}
The class \doxylink{classofeli_1_1_pixmap_widget}{Pixmap\+Widget} is a Qt6 widget to display an image (function draw\+Pixmap in a Paint\+Event is faster than function set\+Pixmap) and gives the possibility to zoom with a mouse wheel event in function of the position of the cursor. Thanks to Johan Thelin. This class is based on a legacy Qt image-\/viewer example.
