Detailed Description

The class PixmapWidget is a Qt6 widget to display an image (function drawPixmap in a PaintEvent is faster than function setPixmap) and gives the possibility to zoom with a mouse wheel event in function of the position of the cursor. Thanks to Johan Thelin. This class is based on a legacy Qt image-viewer example.
