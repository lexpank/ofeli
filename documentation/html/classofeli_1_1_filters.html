Detailed Description

This class implements filters and noise functions for RGB images.
There are two linear filters : a mean filter and a gaussian filter.
Moreover, there are seven operators of mathematical morphology (erosion, dilation, morphological gradient, opening, closing and the both top-hat transforms) with a square for a structuring element.
Furthermore, there are two edge preserving filters : a median filter and a Perona-Malik anisotropic diffusion.
The order filters (i.e. the median filter and the morphological filters) are implemented in a naïve version and in an optimized version (using Simon Perreault's algorithm).
In addition, there are three functions to add noise, implemented with the C++ standard library random distributions: gaussian white noise, impulsional noise or salt and pepper and speckle.

Performs a Perona-Malik anisotropic diffusion with a 8-connected neighborhood.

Parameters
max_iteramaximum number of iterations
lambdaconstant of integration ( \(0\leq \lambda \leq \frac {1} {4}\) ), max value for the numerical stability
kappaconstant of diffusion
optionchoice of the function of conduction coefficient :
1 - \(g\left( \nabla I\right) =e^{\left( -\left( \left\| \nabla I\right\| / \kappa\right) ^{2}\right) }\)
2 - \(g\left( \nabla I\right) =\frac {1} {1+\left( \frac {\left\| \nabla I\right\| } {\kappa}\right) ^{2}}\)
