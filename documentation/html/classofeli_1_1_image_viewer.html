Detailed Description

The class ImageViewer is a graphical user interface using the Qt6 framework (QtCore, QtGui, QtWidgets and QtPrintSupport) to show an image with the active contour, to configure the parameters of the active contour and optionally the preprocessing step and to evaluate two segmentation results thanks to the evaluation window. It is based on a legacy Qt image-viewer example.
