This class defines function objects for the equality comparison operation. Generically, function objects are instances of a class with member function operator() defined. This member function allows the object to be used with the same syntax as a regular function call, and therefore it can be used in templates instead of a pointer to a function. equal_to has its operator() member defined such that it returns true if its two arguments compare equal to each other using operator==, and false otherwise. This class can be used with the template functions list<T>::sort(BinaryPredicate compare) and list<T>::put_away(BinaryPredicate compare).
